# ТурЭксперт

Лендинг для юридических услуг по запуску и защите туристического бизнеса.

## Описание дизайна

**Общий стиль:** Современный корпоративный B2B-дизайн, минимализм, профессиональный бизнес-стиль.

- **Цветовая палитра:** Доминирующий белый фон, темно-синий (navy blue) для акцентов и кнопок, светло-серый для второстепенного текста. Много «воздуха» (отрицательного пространства).

- **Верхняя часть (Hero Section):**
  - Фон: размытое изображение современного офисного интерьера (эффект Gaussian blur).
  - Заголовок: крупный, жирный шрифт без засечек (Sans-serif), цвет темно-синий.
  - Кнопка: прямоугольная, темно-синяя с белым текстом «DISCUSS PROJECT».

- **Информационные карточки:** Три белых прямоугольных блока с закругленными углами и мягкой тенью.
  - Каждая карточка содержит: линейную иконку (ракета, график, щит), заголовок капсом и краткий список услуг.
  - Внизу каждой карточки — текстовая ссылка с подчеркиванием.

- **Графические элементы:** Тонкие геометрические линии и полигональные сетки в углах экрана, создающие ощущение технологичности.

- **Типографика:** Чистые шрифты семейства Sans-serif (похожи на Montserrat или Open Sans).

## Технологии

- Django 6.0
- Tailwind CSS 4.x
- Python 3.13

## Запуск

```bash
cd site
python manage.py runserver
```

## Структура

- `core/` — главная страница, политика конфиденциальности
- `services/` — модель услуг
- `leads` — форма захвата лидов
- `theme/` — настройки сайта (логотип, изображения)
